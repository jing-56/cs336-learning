## 二、UTF-8：字符、字节与 token 的区别

观察 `encode('utf-8')` 的结果，确认字符数不能直接当作字节数。

| 文本 | 字符数（本例） | UTF-8 字节数 |
| --- | ---: | ---: |
| `hello` | 5 | 5 |
| `你好` | 2 | 6 |
| `🙂` | 1 | 4 |

形成的关键认识：

- 字节只有 0–255 共 256 种取值，因此字节级 BPE 初始使用 256 个基础 token。
- 一个 token 的内容是字节串，不要求单独就能解码为完整字符。
- 合并后，一个 token 可以包含多个字节；token ID 是编号，不是字符含义的数值。

## 三、使用作业提供的预分词规则

在 `cs336_basics/bpe.py` 中开始使用 `regex` 和讲义提供的 `PAT`，而非自行设计切分规则。

预分词只划定边界，不丢弃空格、换行和标点。例如：

```text
hello world!  -> ['hello', ' world', '!']
hello  world! -> ['hello', ' ', ' world', '!']
hello\nworld! -> ['hello', '\n', 'world', '!']
```

检查原则：按顺序拼接普通文本的预分词片段，应还原该普通文本。后续处理特殊标记时，需要另外保留它的结构意义。

## 四、从片段频率表到字节序列

使用 `Counter` 统计 `cat cat cat!`：

| 片段 | 次数 |
| --- | ---: |
| `cat` | 1 |
| ` cat` | 2 |
| `!` | 1 |

随后将字符串片段转换为可作字典键的字节元组：

```text
(b'c', b'a', b't')        -> 1
(b' ', b'c', b'a', b't')  -> 2
(b'!',)                  -> 1
```

理解了 `bytes([value])`、元组与字典键的关系，以及 `b'c'` 与普通字符串 `'c'` 的区别。

## 五、完成相邻对统计、选择和单轮修正

相邻对通过 `zip(tokens, tokens[1:])` 取得，统计时乘以片段出现次数，不能仅统计不同片段中的一次出现，也不能跨预分词边界配对。

对上述例子：

| 相邻对 | 加权次数 |
| --- | ---: |
| `(c, a)` | 3 |
| `(a, t)` | 3 |
| `(空格, c)` | 2 |

遵循作业约定，频率相同选择字典序更大的相邻 token 对，因此第一轮选择 `(c, a)`。

合并后：

```text
[c, a, t]       -> [ca, t]
[空格, c, a, t] -> [空格, ca, t]
```

修正采用从左到右、非重叠扫描：匹配一对就消费两个旧 token，否则保留一个。序列本身可以有任意多个 token，“一对”只指每次合并的两个相邻 token。

## 六、区分词表和合并规则

- `vocab`：保存 ID 到字节串的映射，解决最终 token 如何编号、如何还原。
- `merges`：按学习顺序保存合并对，解决新文本按什么优先级合并。
- 新 token 加入词表时，原来的基础 token 继续保留。
- 词表条目数、合并规则数、编码后序列长度是三个不同的数字。
