# 2026-11-07 A1｜OpenWebText 全量分词、编码和本地训练

用完整 OpenWebText 训练语料训练了 **32,000 项 BPE 词表**，并用同一词表编码完整的训练集和官方验证集。在 RTX 3050 Laptop 上，4 层学习模型训练 **20,000 步**，固定验证批次的平均交叉熵从 **10.3782** 降到 **4.9594**。

## 从频率表到 32K 词表

预分词计数与 BPE 合并各自保存结果。第一轮全量合并因电量暂停。第二轮在第 476 轮触发内存保护，当时系统可用内存低于 1.5 GiB。新版用位图保存密集的片段编号，只更新实际发生变化的相邻对，并复用每轮生成的 token 字节串。相同全量频率表下，进入合并阶段的进程工作集从约 3.50 GiB 降至 2.52 GiB。

50 MiB 样本中，新版的 32,000 项词表与 31,743 条合并规则均与原结果逐项一致。全量词表在留出的 10 篇网页文档上产生 7,582 个 token，全部可以逐字还原。

最长普通 token 是由 `ÃÂ` 重复 16 次组成的 64 字节串。它看起来像文本编码遗留的重复模式；仅凭词表无法判断它在原始文档中是如何产生的。TinyStories 的最长普通 token 是带前导空格的 ` responsibility`（15 字节）。

## 用最终词表做跨域对照

沿用 [11 月 4 日对照](2026-11-04-A1-EVALUATION-AND-OWT-BPE.md)的两组验证文档，每组 10 篇。以下用总 UTF-8 字节数除以总 token 数，四组都准确还原了原文。

| 同一组原文 | TinyStories 10K：token 数 / bytes per token | OpenWebText 32K：token 数 / bytes per token |
| --- | ---: | ---: |
| TinyStories（8,457 字节） | 2,084 / 4.0581 | 2,145 / 3.9427 |
| OpenWebText（32,294 字节） | 10,134 / 3.1867 | 7,582 / 4.2593 |

网页样本换回故事词表后，需要多预测 2,552 个 token。带前导空格的 ` legislation` 在故事词表中分为 ` leg`、`is`、`l`、`ation`，在网页词表中保留为一个 token。两套词表的大小也不同；不能用这一组实验单独分离语料和词表大小的影响。

在 1,047,142 字节的完整网页文档前缀上，对纯编码计时三次取中位数。自写 Python 编码约 **0.128 MB/s**，使用相同词表的加速编码约 **5.33 MB/s**，两者输出 ID 逐项一致。以十进制 825 GB 线性外推分别约 **1,795 小时（75 天）**与 **43 小时**。这是单进程、单样本估计，未计读写、解压和结果校验，也没有实际处理 The Pile。两套词表最大 ID 分别为 9,999 和 31,999，均在 `uint16` 的 0–65,535 范围内，每个 ID 只需 2 字节。

## 编码和训练

编码使用训练所得的词表、相同的正则预分词规则和 EOS ID 256。加速编码器在 112 个训练、验证及边界样例上与原 Python 实现的 token ID 逐项一致。全量编码逐块检查字节还原和 EOS 计数，写成支持按批读取的 `.npy`。断点测试模拟了意外中断和文件末尾多写的字节，续跑结果与一次性编码一致。

训练沿用 4 层、模型宽度 128、4 个头、前馈宽度 384、上下文 256、batch 8 的配置。训练批次在完整训练数组上随机取样，每步预测 2,048 个位置。Windows 上的 NumPy 随机下标默认是 32 位整数，大数组的取样入口显式使用 64 位下标，并在 GPU 上验证了超过 2³¹ 的位置。

每 100 步用同一组固定验证批次评估，每次覆盖 20,480 个目标位置。4.9594 是这组批次的平均 loss。20,000 步累计预测的 4,096 万个位置来自随机取样，训练没有遍历一整轮语料。这次使用本地学习配置，课程原始尺寸实验仍待补。

## 从抽样验证到全量验证

重新加载第 20,000 步的同一份存档，核对验证数组的 SHA-256，并复算固定批次 loss **4.95941896**。用 PyTorch 的交叉熵在相同批次上复核，差异低于 0.000001。

全量评估把输入切成连续的 256-token 窗口，目标始终右移一个位置。第一个 token 没有前文，从下标 1 到末尾的 **66,401,097** 个目标各评分一次，最后的 73 个位置也计入。窗口之间重置上下文，不等同于给每个位置使用滚动的最大长度上下文。FP32 评估全程无参数更新。

全量平均交叉熵 **4.98948354**，比固定批次高 **0.03006457**，困惑度为 \(e^{4.98948354} \approx 146.86\)。固定批次适合跟踪同一次训练的变化；全量评估减少了只观察那 20,480 个位置带来的抽样局限，也采用不同的窗口起点。不能把差值全归因于抽样。此前 TinyStories 的全量 loss 是 **1.9715**，但这两项每 token 指标建立在不同的验证文本和分词规则上，不能直接当作两模型质量的倍数。
