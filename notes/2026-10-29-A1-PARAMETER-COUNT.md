# 2026-10-29：当前小模型的参数量核算

参数是训练过程中会被优化器调整的数。权重矩阵有多少个元素，就有多少个参数；每次前向产生的中间向量不属于参数。

本次配置：词表 V=10,000，模型维度 d=64，层数 L=2，SwiGLU 中间维度 f=128，注意力头数 4。Linear 无偏置，输入 Embedding 与输出词表投影不共享权重，RoPE 没有可学习参数，全部参数均参与训练。

## 手算与程序核验

| 部分 | 计算方式 | 参数量 |
| --- | --- | ---: |
| 输入 Embedding | V×d=10,000×64 | 640,000 |
| 两层注意力投影 | L×4×d²=2×4×64×64 | 32,768 |
| 两层 SwiGLU | L×3×d×f=2×3×64×128 | 49,152 |
| 全部 RMSNorm | (2L+1)×d=5×64 | 320 |
| 输出词表投影 | d×V=64×10,000 | 640,000 |
| **合计** | **以上相加** | **1,362,240** |

各项手算和实际模型的逐模块统计完全一致，分类合计也与全部独立参数的统计一致。脚本还打印了每个参数的名称、形状和元素数。

当前结构的一般公式为：

```text
P = 2Vd + L(4d² + 3df + 2d) + d
```

该公式适用于当前无偏置、输入输出权重不共享、标准多头注意力、SwiGLU、两处 Block 内 RMSNorm 和一处最终 RMSNorm 的结构；其他结构需重新计数。

## 每一项怎样理解

Embedding 为 10,000 个 token 各准备一个 64 维可学习向量，因此是 640,000 个数。输出层将 64 维特征映射为词表中 10,000 个候选的 logits，需要另一张独立权重矩阵，也是 640,000 个参数。

每层注意力有 Q、K、V 和输出投影四张 64×64 权重矩阵。式子里的 4 是这四张矩阵，不是注意力头数。四个头是把总共 64 维拆成四份，每头 16 维，不会再额外乘一次头数。

SwiGLU 有三张矩阵，每张都有 64×128=8192 个参数，每层共 24,576，两层 49,152。

每个 RMSNorm 只有一个长度 64 的可学习缩放向量 g，共五处，合计 320。之前移除 RMSNorm 时模型参数减少 320，与这里对应；普通 SiLU 用两张宽 192 的矩阵，参数仍与三张宽 128 的 SwiGLU 矩阵配平。

输入与输出词表矩阵合计 1,280,000 个参数，占总数约 93.96%。这是当前词表较大、模型较窄且只有两层的结果，不能推广到所有语言模型。

## 参数与中间数据

- 当前 RoPE 有 2048 个固定 buffer 元素，属于不参与训练的 sin/cos 查找表，不计入可学习参数；固定表仍占存储空间并参与前向计算。
- 残差相加、softmax、SiLU 激活、因果遮罩和拆分头的 reshape 都不增加可学习参数，但仍可能消耗计算或内存。
- batch size 或输入长度改变时，重复使用同一套权重，不会因此增加参数量；中间张量、每步计算量和运行内存则会变化。延长本实现的上下文还会扩大 RoPE 固定表。
