# A1：BPE 分词器小样本实验记录

日期：2026-10-25

在约 5 MB 的 TinyStories 样本上训练了一个包含 10,000 个 token 的字节级 BPE 词表，其中包括 256 个基础 token、1 个特殊 token 和 9,743 个合并产生的 token。正常运行耗时约 14.65 秒，截至训练结束的进程峰值驻留内存约为 48.99 MiB。

最长普通 token 为 `b' congratulations'`，长度为 16 字节，包含开头空格。在一段未参与训练的 98 字节文本上，编码结果为 22 个 token，约 4.45 bytes/token，并能完整还原原文。

性能分析显示，主要开销集中在每轮扫描候选相邻对、选出最高频对的过程。上述结果来自小样本实验，尚不能代表完整 TinyStories 数据集上的时间、内存和泛化表现。

补充：测得的内存是整个进程的峰值驻留内存，包含解释器和依赖。流式编码的内存限制测试尚未在 Linux 环境验证。
